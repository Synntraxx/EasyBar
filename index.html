Raccourcis & Commandes

⌨️ Création & Raccourcis Clavier

  • Ctrl + C / Ctrl + V : Duplique instantanément l'étiquette sélectionnée avec son titre et ses dimensions (décalée sur la feuille).
  • Ctrl + V (général) : Collez un texte/code depuis n'importe où pour générer une nouvelle étiquette.
  • SUPPR (Delete) : Supprime immédiatement l'étiquette sélectionnée.
  • Saisie Sidebar : Tapez une valeur, choisissez le type et cliquez sur "Ajouter à la feuille".

🖱️ Clic-Droit sur une Étiquette

  • Titre : Ajouter ou modifier un titre proportionnel (ex: FRAIS, PGC).
  • Modifier le code : Double-cliquez directement sur le code ou utilisez l'option.
  • Masquer/Afficher la valeur : Affiche ou masque la valeur textuelle sous les barres.
  • Alignement : Centrer horizontalement/verticalement ou aligner sur les arêtes.
  • Dupliquer / Formater : Duplique l'étiquette ou change son type (CODE128, EAN-13, CODE39).

📄 Disposition sur la Feuille A4

  • Déplacement : Glissez-déposez les étiquettes. Elles s'aimantent automatiquement sur une grille de 15px et se calent à 0 sur les bords (tolérance 25px).
  • Taille : Utilisez la poignée en bas à droite pour redimensionner.
